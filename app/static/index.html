RepoTriage

Payload Intelligence Platform — GitHub or GitLab file URL → hashes, enrichment, extraction, IOCs, MITRE and CTI summary.

v4 alpha
Opened from RepoTrace — file URL prefilled; analysis starts automatically when requested.
Accepts any GitHub/GitLab URL that hosts a file: blob/raw, repo, tree, gist, release asset, archive. Repo/tree URLs auto-pick a root payload (archives preferred). Private repos need GITHUB_TOKEN / GITLAB_TOKEN. Browser gets metadata/CTI only — never sample bytes.
